# 리치온 아카데미 (RICHON Academy) — 홈페이지

부동산 스터디 강의 소개 · 신청 정적 웹사이트 (HTML/CSS/JS, 빌드 불필요).

---

## 폴더 구성

```
richon-academy/
├─ index.html                     ← 메인 (페이지 이동 버전)
├─ richon-apply.html              ← 강의 신청/결제 페이지
├─ popup-version/
│   └─ index.html                 ← 대안: 신청이 '팝업(모달)'으로 뜨는 단일파일 버전
├─ google-apps-script/
│   └─ richon-apps-script.gs      ← 신청 자동 안내메일 스크립트(선택)
└─ README.md
```

### 두 가지 버전 (하나만 배포하세요)

- **페이지 이동 버전 (기본, 루트):** `index.html` + `richon-apply.html`.
  신청 버튼을 누르면 별도 신청 페이지로 이동합니다. 이 두 파일을 함께 올리세요.
- **팝업 버전:** `popup-version/index.html` 한 파일.
  신청 버튼을 누르면 같은 화면에서 팝업으로 뜹니다. 이 파일 하나만 있으면 됩니다.
  → 이 버전으로 쓰려면 `popup-version/index.html`을 루트로 옮겨 `index.html`로 쓰세요.

## 배포 방법 (셋 중 택1)

정적 사이트라 빌드가 필요 없습니다. 폴더째 올리면 끝.

- **Cloudflare Pages (무료·상업용 허용, 추천):** 대시보드 → Pages → 업로드/깃 연결.
- **Netlify (무료):** 사이트를 드래그&드롭 또는 깃 연결.
- **Vercel:** 상업용은 Pro($20/월)가 필요합니다. 무료로 쓰려면 위 두 곳 권장.

도메인은 별도(연 1~3만원). 구입 후 호스팅에 연결하세요.

## 배포 전 교체 항목 (중요)

각 HTML 파일의 아래 `{{ }}` 값을 "찾아 바꾸기"로 실제 값으로 교체하세요.

| 플레이스홀더 | 넣을 값 |
|---|---|
| `{{구글폼URL}}` | 신청서(구글 폼) 링크 |
| `{{결제링크URL}}` | (선택) 토스페이먼츠/카카오페이 등 결제 링크 |
| `{{입금계좌}}` | 무통장입금 계좌 (예: 국민 000000-00-000000 예금주 ○○○) |
| `{{블로그URL}}` `{{카페URL}}` `{{유튜브URL}}` `{{오픈채팅URL}}` `{{카톡상담URL}}` | 각 채널 링크 |

- 강의 가격: `richon-apply.html`(및 popup 버전) 안 `COURSES`의 `price` 값을 실제 금액으로.
- 월간 일정: `index.html` 하단 `<script>`의 `EVENTS` 배열을 매달 수정.
- 이미지: 현재 모든 이미지 자리는 블루프린트(체크무늬) 자리표시입니다. 실제 이미지를 받으면 해당 자리를 `<img src="...">`로 교체하세요.

## 신청 → 자동 접수 → 자동 안내 (선택)

1. 구글 폼 생성(이름·이메일·연락처·과정·입금자명·현금영수증 정보) → 응답을 구글 시트로 연결.
2. 시트 → 확장 프로그램 → Apps Script에 `google-apps-script/richon-apps-script.gs` 붙여넣기.
3. `setupTrigger` 1회 실행(권한 허용). 이후 신청 시 신청자에게 안내 메일 자동 발송.
   → 댓글로 일일이 응대할 필요가 없습니다.

> 참고: 구글 폼 자체는 카드 결제를 처리하지 못합니다. 실제 카드 결제·자동 현금영수증이 필요하면
> 월 고정비 없는 결제링크(토스페이먼츠/카카오페이 등)를 `{{결제링크URL}}`에 연결하세요.
